فايب — نسخة المشروع الكاملة FIX-17
تاريخ التصدير: 9 سبتمبر 2026

هذه حزمة مصدر الويب والخادم للنسخة المنشورة، وليست تطبيق IPA ولا مشروع Xcode أصلياً.
الرابط المنشور: https://vibe-social-nights.bb0949.chatgpt.site

ابدأ هنا
1. فك ضغط ZIP، ثم افتح مجلد Vibe-Full-Project.
2. واجهات التطبيق: public/index.html وpublic/app.js وpublic/style.css.
3. السينما المشتركة: public/cinema.html وcinema.js وcinema.css.
4. الخادم: server/worker.mjs وserver/cinema.mjs.
5. مخطط قاعدة البيانات: db/schema.ts، وترحيلها: drizzle/.
6. الوثائق التقنية المتتابعة: docs/ARCHITECTURE-AR.md.
7. ملاحظات إعداد الدعم: server/SETUP.md. وثائق appstore مسودات وليست إثبات قبول Apple.

التشغيل والبناء
يلزم Node.js وnpm. اختبارات السينما تستخدم node:sqlite؛ البيئة التي اختبرناها Node 24.
من Terminal داخل مجلد المشروع:
npm ci
npm run build
npm test
npm run test:cinema

البناء موجود أيضاً في dist/server/index.js ويحتوي ملفات الواجهة بداخله.
هذا Worker يحتاج بيئة Cloudflare متوافقة، وليس خادم Express يعمل بأمر node عادي.
لمعاينة الواجهة فقط يمكن تقديم public عبر خادم ملفات محلي. لا تعمل API السينما والدعم بمجرد فتح index.html من القرص، وقد يقيّد المتصفح الميكروفون أو الكاميرا خارج سياق آمن.

النقل إلى Codex أو مطوّر آخر
افتح مجلد المشروع كاملاً وابدأ بهذا الدليل. حافظ على اسم ونمط المشروع الحاليين.
.openai/hosting.json يشير إلى موقع فايب الموجود ويحدد ربط D1 باسم DB. هذا المعرف ليس كلمة مرور ولا يمنح صلاحية التعديل وحده. عند متابعة نفس موقع Sites لا تنشئ موقعاً بديلاً دون قصد.
لنقل التطبيق إلى استضافة أخرى يجب إعداد D1 وتطبيق ترحيلات drizzle مرة واحدة، وتحديث trustedOrigin في server/worker.mjs ومواضع عنوان الموقع في الاختبارات والإعدادات. لا تعِد تطبيق ترحيل منشور على قاعدة قائمة دون سجل ترحيلات صحيح.
لا تتضمن الحزمة بيانات الجلسات الحية الموجودة بقاعدة D1 أو أسرار الاستضافة أو مفاتيح API أو سجل Git أو node_modules. يعيد npm ci تثبيت الاعتماديات من package-lock.json.

الميزات الحالية
- واجهة عربية/إنجليزية، والإنجليزية افتراضية.
- بروفايل مرتب، اهتمامات وتايب جاهزة، بايو ورابط HTTPS، وصور وأفاتار وبرومبتات.
- تسجيل صوت بالضغط، إرسال محلي عند رفع الإصبع، قفل للأعلى، وإلغاء لليسار.
- صور محلية مضغوطة دون معاينة إضافية؛ عارض صور وروابط فيديو.
- سينما مشتركة بروابط دعوة، تحكم للمضيف وحالة على D1؛ مزامنة تقريبية تعتمد على الاتصال ومزود الفيديو.
- شروط وخصوصية وقواعد مجتمع مفصلة داخل قائمة الحساب.

ما لم يُربط بعد
- إنشاء حساب حقيقي وGoogle/Apple login وحفظ بروفايل دائم.
- تسليم رسائل الشات والصوت والصور إلى مستخدم آخر أو غرف صوت WebRTC فعلية.
- دفع فعلي: Premium معاينة مجانية، 20 ريالاً سعر شهري مخطط.
- دعم OpenAI يحتاج إعداد أسرار الخدمة وصلاحياتها؛ ليس مرتبطاً باشتراك ChatGPT الشخصي.
- فريق إشراف وبلاغات فعلية وحذف حساب حقيقي وحماية تمنع تصوير الشاشة.
- لا مشروع Xcode أو IPA ضمن هذه الحزمة، ولا اختبار على آيفون فعلي ولا اعتماد من Apple.

الملف README-original.md يحتفظ بملاحظات أقدم قد تتعارض مع التحسينات الأخيرة؛ هذا الدليل وسجل FIX-17 في الوثائق هما مرجع الحالة الحالية.
